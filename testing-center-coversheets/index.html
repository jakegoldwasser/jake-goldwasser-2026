How this works

What runs where

This entire tool is one self-contained web page — the form, the coversheet layout, and printing logic are all plain HTML/CSS/JavaScript running in your browser tab. There is no server: nothing you type is sent anywhere, not to a database, not to Anthropic or Claude, not anywhere else. "Print all coversheets" just calls your browser's own native print dialog on the page as currently rendered, which is also how "Save as PDF" gets you a PDF without this tool needing to generate one itself.

What that means for student data

Names, grades, accommodation flags, and everything else you enter live only in this browser tab's memory for as long as the tab is open. Nothing is uploaded, logged, or retained anywhere — reload the page or close the tab and it's gone. That also means there's nothing to lose track of after you're done printing: no residual copy sitting on a server somewhere.

Full source code

Every line of code that runs on this page is in one file, published on GitHub: github.com/jakegoldwasser/testing-center-coversheets. Open it and you're reading exactly what ran in your browser — there's no separate, hidden build.
